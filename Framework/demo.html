💻 9. Common Usage Examples

Create a new note:

const note = chalkboard.createNote(); console.log('New note created:', note);

Save current note:

chalkboard.saveNote() .then(() => console.log('Note saved')) .catch(error => console.error('Save failed:', error));

Load all notes:

chalkboard.loadNotes() .then(notes => console.log(`Loaded ${notes.length} notes`)) .catch(error => console.error('Load failed:', error));

Use UI notifications:

chalkboard.createNotification('Operation successful!', 'success', 3000); chalkboard.createNotification('An error occurred', 'error', 5000);

Read note aloud:

chalkboard.readNoteAloud(); // Single note chalkboard.readSelectedNotes(); // Multiple selected notes

Export note:

chalkboard.exportNote('markdown'); // .md chalkboard.exportNote('txt'); // .txt chalkboard.exportNote('pdf'); // .pdf (requires html2pdf)

🚀 10. Integration Tips

  • Firebase Setup: Ensure Firebase SDK is loaded before initializing the framework
  • CSS Styling: Include the styles.css file for consistent UI appearance
  • HTML Structure: Create DOM elements with IDs matching your initialization config
  • Error Handling: Always use .catch() to handle promise rejections
  • User State: Check if user is authenticated before performing operations
  • Text-to-Speech: Test browser compatibility before deploying
  • Export PDF: Include html2pdf library for PDF export: <script src="https://cdnjs.cloudflare.com/ajax/libs/html2pdf.js/0.10.1/html2pdf.bundle.min.js"></script>
